# Using the interactive viewer

driftplots is a lightweight tool. It has two modes, interactive mode and matplotlib mode. It can
take as input a path to a kilosort sorting output or a SpikeInterface sortinganalyzer
(which must have the extensions computed as here XXX).

Interactive mode is useful to comparing two sessions (e.g. that are inputs to multi-session unit matching).
In interactive mode, you can click on the scatter points which will display the *template* associated with
that spike. This means you can check whether the similar-looking templates (i.e. the same neuron) are found
on the same place on the probe across sessions.

Alternatively, `matplotlib` mode plots the drift map as a matplotlib figure. This is similar to the
drift maps generated by Kilosort, though it allows more customisation, including the 1D histogram of
the raster plot, and gives you direct access the theo figure. This can be useful for generating
PDF or HTML displays of your data to get an overview of many sessions, such as shown in this example.

Here we go through the basics of each method. To see more, see our examples in the repository
or on the documentation.

WARNINGS: designed for NP1 probes, will work for Cam Neurotech or NeuroNexus but not well tested. Please get in touch.

For kilosort, spiek clusters is attempted to be used.

# Using the interactive Viewer

The interactive viewer can be used to open a Qt interface that allows you to select
the individual spikes on the driftmap. Once selected, the template for that driftmap will
be displayed on the right-hand side.

Note that this template is unwhitened and unscaled (see HERE for details), so will display the same for each spike associated
with the same template. This was chosen due to the difficulty of reconstructing individual waveforms from
kilosort outputs, and because the main purpose of the interactive mode is to check that templates are identifiable
across sessions (rather than inspect the individual, nosiy waveforms).

See the API documentation for a full list of arguments, and the section below for details on
how the displayed spikes can be processed (e.g. to cut down their number, or exclude noise only spikes).

Show code for single data. Link to example for multiple data.

```python
from driftplots import DriftMapView

plotter = DriftMapView(
    "/path/to/kilosort/output",
    exclude_noise=True
)

```

# Using matplotlib

The XXX function will generate the matplotlib plots and return these. These take the same arguments
as XXX (e.g. for processing spikes (Link)), alongside additional arguments that allow generating the 1D heatmap

```python
import matplotlib.pyplot as plt
import spikeinterface as si

from driftplots import DriftMapView

analyzer = si.load_sorting_analyzer("/path/to/analyzer.zarr")

plotter = DriftMapView(analyzer)

fig = plotter.drift_map_plot_matplotlib(
    exclude_noise="KSLabels",
    add_histogram_plot=True,
    weight_histogram_by_amplitude=True,
)

plt.show()

```


# Aligning amplitudes

The color scaling for amplitudes are based on the amplitudes for that single session. It can be useful
to use the same colormap scaling for all plots, to ensure they are the same across all plots.

To do this, pass a list of paths to kilosort outputs or sortinganalyzers to the `get_amplitudes()`
function, which can be used to find the max or min of all amplitudes and set the color map
and amplitude exclusion accordingly. These arguments work the same for interactive or matplotlib mode.

```python
import numpy as np

analyzer = si.load_sorting_analyzer("/path/to/an/analyzer.zarr")

SORTING_SESSIONS = [
    "/path/to/a/sorting",
    analyzer
]

all_spike_amplitudes = get_amplitudes(
    SORTING_SESSIONS, exclude_noise=False, concatenate=False
)

min_cutoff, max_cutoff = np.percentile(concat_spike_amplitudes, (0, 95))

app = QtWidgets.QApplication([])

panels = []
for path_or_analyzer in SORTING_SESSIONS:
    plotter = DriftMapView(path_or_analyzer)

    plot = plotter.drift_map_plot_interactive(
        filter_amplitude_mode="absolute",
        filter_amplitude_values=(min_cutoff, max_cutoff),
        amplitude_cmap_scaling=(min_cutoff, max_cutoff),
        n_color_bins=25,
    )

    panels.append(plot)

multi = MultiSessionDriftmapWidget(panels)

app.exec()

```

# Processing the data

When a sorting analyzer is used to create the driftmap, only the number
of spikes used to compte the analyzer are used. This is defined by the
XXX argument on XXX.

When loading kilosort output, every detected spike is loaded from disk.

These spikes may include noise spikes, spuriously low or high amplitudes spikes,
or be so numerous as to slow down the plot generation. These can be dealt with
with hte `exclude_noise`, `` and ``, and `` parametrs repescetively. See the
